## Project Overview

This is a Nuxt 4 playground project using Vue 3, configured with TypeScript, ESLint, and Nuxt Test Utils. The project uses pnpm as the package manager.

## Development Commands

```bash
# Install dependencies
pnpm install

# Start development server (http://localhost:3000)
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview

# Generate static site
pnpm generate

# Lint code
npx eslint .
```

## Architecture

### Application Structure

- **app/app.vue**: Root component that wraps all pages with `<NuxtLayout>` and `<NuxtPage>`
- **app/pages/**: File-based routing - each `.vue` file becomes a route
- **app/layouts/**: Layout components (currently `default.vue` with header/footer structure)

### Nuxt Configuration

- **nuxt.config.ts**: Main configuration file
  - Devtools enabled
  - Modules: `@nuxt/eslint`, `@nuxt/test-utils`
  - Compatibility date: 2025-07-15

### TypeScript Configuration

TypeScript is configured via project references to auto-generated `.nuxt/tsconfig.*` files. Do not manually edit the root `tsconfig.json`.

### ESLint

ESLint configuration extends from `.nuxt/eslint.config.mjs` (auto-generated by Nuxt). Custom rules can be added in `eslint.config.mjs`.

## Key Conventions

- Use Composition API with `<script setup lang="ts">` in Vue components
- Nuxt auto-imports components, composables, and utilities - no explicit imports needed for Nuxt/Vue APIs
- Pages are auto-registered based on file names in `app/pages/`
- Layouts are referenced by name without the `.vue` extension
- use scss for styles
- use camelCase components props names, even when using component in template
